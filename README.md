# LAMZU Battery & Polling Rate Monitor

Легковесная утилита для Windows (системный трей), расширяющая возможности беспроводных мышек **LAMZU** (Maya, Maya X, Atlantis, Thorn, Paro, Inca и др.).

---

## Основные возможности

1. **Мониторинг заряда в трее Windows**:
   - Отображение точного процента заряда прямо на значке возле часов.
   - Цветовая индикация: зеленый (>30%), оранжевый (16–30%), красный (≤15%), значок зарядки при питании по кабелю.
   - **Устранение бага со сном**: когда мышь засыпает, приложение сохраняет последний реальный заряд и не сбрасывает значение в 0%.

2. **3-этапное циклическое переключение кнопки на дне мыши**:
   - Нажатие физической кнопки на основании мыши переключает режимы:
     - **Этап 1**: Киберспортивный режим (High-Speed Mode) + **2000 Гц**
     - **Этап 2**: Экстремальный режим (20K FPS Mode) + **4000 Гц**
     - **Этап 3**: Обычный режим (энергосбережение) + **1000 Гц**
   - Прямой перехват аппаратных прерываний через HID Report ID 4 (нулевая задержка).
   - Частоты для каждого этапа настраиваются в меню приложения (500, 1000, 2000, 4000, 8000 Гц).

3. **Оптимизация производительности в играх**:
   - В полноэкранных 3D-играх фоновый опрос аккумулятора приостанавливается (0% нагрузки на процессор и радиоканал).
   - При выходе из игры или сворачивании по `Alt+Tab` уровень заряда обновляется моментально.

4. **Современный темный интерфейс**:
   - Нативная темная строка заголовка Windows 10 / 11.
   - Четкие контрастные бейджи этапов и параметров без сбоев шрифтов.
   - Всплывающие системные уведомления Windows при смене частоты.

5. **Поддержка проекта (Донаты)**:
   - Встроенная кнопка поддержки автора в окне настроек и контекстном меню трея.
   - Возможность указать свою ссылку для пожертвований (Boosty, DonationAlerts, ЮMoney, SBP и т.д.) через интерфейс или `config.json`.

---

## Установка и запуск

- **Готовый установщик**: запустите `LAMZU_Battery_Setup.exe` на Рабочем столе — он установит приложение, настроит ярлыки и автозагрузку с Windows.
- **Портативная версия**: запустите `LamzuBatteryTray.exe`.

---

## Сборка из исходников

```bash
git clone https://github.com/your-username/lamzu-battery-monitor.git
cd lamzu-battery-monitor
pip install -r requirements.txt
python main.py
```

Сборка одного исполняемого файла через PyInstaller:
```bash
pyinstaller --noconfirm --clean --onefile --windowed --icon="app_icon.ico" --name="LamzuBatteryTray" "main.py"
```
