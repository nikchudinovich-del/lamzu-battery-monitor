# LAMZU Battery & Polling Rate Monitor

Легковесная утилита для системного трея Windows с глубокой черной темой (AMOLED Dark), расширяющая возможности мышек **LAMZU** (Maya, Maya X, Atlantis, Thorn, Paro, Inca и др.).

---

## Возможности

1. **Индикация заряда в трее (Lanczos 4x Super-Sampling)**:
   - Высококонтрастная глубокая черная плашка (Obsidian Black) с неоновым контуром.
   - Идеально четкий геометрический шрифт цифр (**Bahnschrift / Segoe UI Bold**).
   - Индикация цветом:
     - 🟢 **Неоновый изумрудный**: заряд > 30%
     - 🟡 **Неоновый янтарный / золото**: заряд 16–30%
     - 🔴 **Неоновый красный**: заряд ≤ 15%
     - ⚡ **Кибер-голубой с молнией**: мышь заряжается по кабелю
     - ⚪ **Графитовый**: мышь в спящем режиме (значение заряда сохраняется, нет сброса в 0%).

2. **3-этапное циклическое переключение кнопкой на дне мыши**:
   - Нажатие физической кнопки на основании мыши мгновенно переключает режимы:
     - **Этап 1**: Киберспортивный режим (High-Speed) + **2000 Гц**
     - **Этап 2**: Экстремальный режим (20K FPS) + **4000 Гц**
     - **Этап 3**: Обычный режим (энергосбережение) + **1000 Гц**
   - Прямой перехват аппаратных прерываний через HID Report ID 4 (нулевая задержка).

3. **Сенсор мыши (DPI и Высота отрыва LOD)**:
   - **Быстрый выбор DPI**: 400, 800, 1200, 1600, 2400, 3200 прямо из меню трея в 1 клик.
   - **Произвольный DPI**: возможность задать любое значение от 50 до 30 000 с шагом 50 (оси X и Y строго синхронны).
   - **Высота отрыва (LOD)**: 0.7 мм, 1.0 мм или 2.0 мм.
   - *Безопасность*: параметры сенсора меняются ТОЛЬКО тогда, когда пользователь сам выбирает их в меню или нажимает «Сохранить». При установке и запуске программы существующие настройки мыши не перезаписываются!

4. **Управление подсветкой (Цвет светодиода мыши)**:
   - Переключение цвета светодиода мыши в 1 клик прямо из трея или через окно настроек.
   - Палитра быстрых пресетов: Изумрудный, Кибер-голубой, Фиолетовый, Красный, Золотой янтарь, Белый.
   - Поддержка полной палитры Windows для выбора любого произвольного оттенка RGB.

5. **Энергосбережение и Таймаут сна**:
   - Настройка времени до перехода в режим сна: 10 с, 30 с, 1 мин, 5 мин, 10 мин, 30 мин.

6. **Оптимизация производительности в играх**:
   - В полноэкранных 3D-играх фоновый опрос аккумулятора приостанавливается (0% нагрузки на CPU и радиоканал).
   - Мгновенный опрос при выходе из игры или нажатии `Alt+Tab`.

7. **Поддержка автора проекта (Донат)**:
   - Виртуальная карта для поддержки разработчика:
     - **Номер карты (СБП)**: `2204 3110 1790 0938`
     - **Банк**: **Яндекс Банк (СБП)**
   - Кнопка «Скопировать номер карты» в один клик.

- **Автоматический установщик**: запустите `LAMZU_Battery_Setup.exe` на Рабочем столе — установка пройдет за 1 секунду.
